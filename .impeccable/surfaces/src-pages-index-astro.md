# Surface: AW Digital Solutions site (all routes)

Mode: Persuade. Audience: business owners judging whether two founders can be trusted with their site. Action: send a project inquiry (contact form). Proof: the site itself; no clients, testimonials, stats or awards exist and none may appear. Constraints: experimental nav, neumorphism as accent on muted base, motion as core with reduced-motion + no-JS fallbacks; no testimonials, events, hours, location.

## Direction contract

THESIS: The site is a construction document set for the studio itself: every page is a sheet (A-00 to A-04) drawn on vellum, so "we build properly" is shown as drafting discipline rather than claimed. Refuses the dark-SaaS-agency hero with neon gradient and logo wall.

OWN-WORLD: Cool grey drafting vellum (#E4E5E1), graphite ink (#1C1E21), non-photo blue construction lines (#8FB3D9, decorative only), one cobalt (#2335C8) for action and for the blueprint. Hierarchy by drafting line weight (0.5/1/2px), not boxes. One face, Archivo, swung across its width axis: expanded for titles, condensed uppercase for annotation, normal for prose. Neumorphic extrusion only on tools: buttons, inputs, nav toggle, the scale bar.

STORY: Visitor reads the mission verbatim, sees the three standards measured live on this very page (weight, motion preference, contrast), understands Build / Redesign / Manage, sees the real process, meets Alex and Will, starts a project.

FIRST VIEWPORT: Left 7/12: mission as display title, expanded Archivo, ~clamp(2.6rem,7vw,6rem), cobalt primary button "Start a project" + secondary "See the process". Right 5/12: a drafted elevation of a web page that draws itself, with dimension lines and three live callouts. Title block fixed bottom-right (desktop) / docked bottom (mobile): sheet number, sheet title, Index toggle.

FORM: Architect's construction drawing set, candidate 7 of 7 on the ordered list (seed ddc0a11b). Signature interaction: Index toggle floods the screen into a cobalt blueprint drawing index (clip-path wipe from the title block), sheets listed large; focus-trapped dialog. Motion grammar: lines draw (stroke-dashoffset) then content settles; cross-document view transitions between sheets. Raises: line-weight hierarchy, never enclosure (from cracktro); numbers are measured, never claimed (from VU bridge); page descends in construction order (from sampler); one line system draws section boundaries (from guide map).

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
